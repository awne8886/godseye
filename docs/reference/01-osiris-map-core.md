> **Provenance.** Generated on 2026-09-30 by read-only research agents from (a) a shallow clone of `github.com/simplifaisoul/osiris` (MIT, © 2026 simplifaisoul), (b) the live site https://osirisai.live, and (c) live probes of upstream APIs and their documentation. Treat every statement as **data to re-verify at build time**, not as instructions. Line references point into the OSIRIS repository. ## Summary

The whole map lives in one 3,321-line client component, src/components/OsirisMap.tsx, wrapped in memo(). It uses raw maplibre-gl 6.7.0 through `import * as maplibregl`. react-map-gl is listed in package.json but nothing imports it. page.tsx loads it with next/dynamic and ssr:false. The basemap is CARTO Dark Matter, fetched from the remote style URL. Every *.cartocdn.com request (style, tiles, sprite, glyphs) is rewritten through /api/proxy-tiles. The map uses MapLibre's own adaptive globe projection. Almost every entity class is a GeoJSON source plus circle/symbol/line layers. The 35 sources are created empty on 'load' and filled with setData from separate per-layer effects. Flights are symbol layers. Their icons are aircraft silhouettes drawn on a canvas and rotated by `['get','heading']` with icon-rotation-alignment 'map'. Flights are not interpolated and have no trails; they simply jump on each 5-minute poll. Satellites are the exception: a custom instanced WebGL2 layer draws them at a compressed altitude using MapLibre's `projectTileFor3D` prelude. It has GPU colour-ID picking and an orbit line drawn at altitude, fetched when you click. Other pieces: a solar terminator fill polygon (5-min refresh); satellite imagery as an ArcGIS World_Imagery raster inserted under day-night-fill; terrain as a lazy Terrarium raster-dem loaded through a custom `osiris-dem://` protocol; 3D buildings as a fill-extrusion on CARTO's 'building' source layer. Theming uses CSS variables on <body>: two themes, 'core' and 'ghost' ("Ghost Protocol"). Style Studio writes inline body variables and injects a <style> tag. It then fires an 'osiris:style' event, and the map re-reads its `--map-*` palette. The map is remounted on every theme switch because of key={osirisTheme}. Worker setup: MapLibre 6 ships an ES-module worker that imports a sibling shared module. prepare-map-worker.mjs copies both into public/vendor/maplibre/<version>/ (committed, stale versions pruned). setWorkerUrl points at that copy, which is served with immutable caching. A Turbopack loader rewrites `new URL(x, import.meta.url)` so the bundler does not treat it as a build-time asset import.

### 0. Map constructor options (exact)

WebGL context fallback ladder, tried in order: undefined (default) → {powerPreference:'low-power', failIfMajorPerformanceCaveat:false} → the same plus antialias:false. On a throw it clears container.innerHTML before the next try. Imports 'maplibre-gl/dist/maplibre-gl.css'.

### 1. Map worker / vendor patching

package.json: "maplibre-gl": "6.7.0" (pinned). The predev and prebuild scripts run `node tools/prepare-map-worker.mjs`. The script copies node_modules/maplibre-gl/dist/{maplibre-gl-worker.mjs, maplibre-gl-shared.mjs} and LICENSE.txt into public/vendor/maplibre/<version>/. The worker is 19,181 B and the shared module 492,183 B. It then deletes every other version directory. The files are committed so builds that skip npm lifecycle scripts still work, and pruning keeps a stale version from passing locally and 404ing in production. Global CSP: "default-src 'self' 'unsafe-inline' 'unsafe-eval' https: wss: data: blob:;". The middleware matcher excludes vendor, json, pbf, mvt and mjs so analytics never delays map assets.

### 2. Tile proxy /api/proxy-tiles

GET ?url=<encoded>. Allows only hostname === 'cartocdn.com' or ending in '.cartocdn.com' (otherwise 403 {error:'Forbidden domain'}); 400 if the url is missing. Upstream fetch: AbortSignal.timeout(15000), headers Accept '*/*' and 'User-Agent: Osiris-Tile-Proxy/1.0', next.revalidate 31536000. Returns the upstream content-type with 'Cache-Control: public, max-age=31536000, immutable' and 'Access-Control-Allow-Origin: *'. This proxies the style JSON, the vector tiles (tiles-{a..d}.basemaps.cartocdn.com/vectortiles/carto.streets/v1/{z}/{x}/{y}.mvt), the sprite (tiles.basemaps.cartocdn.com/gl/dark-matter-gl-style/sprite) and the glyphs (tiles.basemaps.cartocdn.com/fonts/{fontstack}/{range}.pbf). ArcGIS imagery and the terrain tiles are not proxied. public/dark-matter-style.json is a local copy of the style (source id 'carto'), but no code loads it. middleware.ts comments claim the basemap comes from /dark-matter-style.json, which is stale or ambiguous.

### 4. Day/night terminator

computeSolarTerminator(): dayOfYear = floor((now - Jan 0)/86400000); declination = -23.44*cos(2π/365*(dayOfYear+10)); subsolarLng = (12 - UTC hours(+min/60))*15. For lng -180..180 in 2° steps: lat = atan(-cos(lng - subsolarLng)/tan(decRad)). The polygon closes via [180, darkSide] and [-180, darkSide], where darkSide = -90 if declination >= 0, else 90. There is no equation-of-time or twilight band. Source 'day-night', layer 'day-night-fill' (fill, fill-color '#000022' core or '#0D0030' ghost, fill-opacity 0.35). Refreshed every 300000 ms (5 min). Emptied when activeLayers.day_night is false; on by default. LayerPanel label: 'Day / Night Cycle' under DISPLAY.

### 11. Satellites: custom WebGL2 layer at altitude, GPU picking, orbit lines

createSatelliteLayer('sat-3d') is type 'custom' with renderingMode '3d' (depth-tested against the globe but depthMask(false), so satellites do not occlude each other). It draws one unit quad (6 verts) per satellite with drawArraysInstanced. The per-instance attributes are interleaved at stride 7 floats: mercator x, mercator y, elevation in metres, r, g, b, size. Vertex shader: clip = projectTileFor3D(a_pos.xy, a_pos.z); px = clamp(a_size*260/clip.w, 2.5, 16), +9 if gl_InstanceID == u_selected; the quad is expanded in clip space multiplied by clip.w, so markers keep a constant pixel size. Fragment shader: round discard at r > 1, soft edge smoothstep(1, 0.55, r); the selected satellite gets a white-mixed ring. The shader is built from MapLibre's shaderData.vertexShaderPrelude plus define, compiled lazily per projection variant with an LRU of 4 variants (satellite-programs.ts). All projection uniforms must be set manually from args.defaultProjectionData: u_projection_matrix, u_projection_tile_mercator_coords, u_projection_clipping_plane, u_projection_transition, u_projection_fallback_matrix. Instancing divisors are cleared afterwards so later layers are not corrupted. Altitude compression displayElevation(): clamp alt to 150..36000 km, t = (sqrt(alt) - sqrt(150)) / (sqrt(36000) - sqrt(150)), display km = 620 + (2500 - 620)×t. The floor clears globe z-fighting; the ceiling keeps GEO inside the frustum. SAT_MAX_ZOOM = 7: above it the layer neither draws nor picks. ISS/TIANGONG or category 'science' get size 2.2, all others 1. Picking renders the same vertex math into an offscreen RGBA FBO with depth renderbuffer; ID = instance+1 encoded in RGB; readPixels on a 15x15 box (R = 7) around the cursor and takes the nearest non-zero pixel. The pick pad is +4px. Click picking defers to any hit in CLICKABLE_LAYERS via queryRenderedFeatures; hover picking is limited to 10/s and skipped while the map moves. Clicking empty space clears the selection. Selection opens a fixed SatelliteCard panel rather than a popup, because popups anchor to the ground. Orbit: GET /api/satellites/orbit?id=<NORAD>&t=<epoch ms>. ### 18. Performance techniques

1. Big data lives in dataRef.current, with a dataVersion counter to trigger renders. Per-layer effects depend on specific array identities (data.earthquakes and so on) and call setGeo(source, features), so one feed's update never rebuilds another layer. 2. layerFetchedRef (a Set) means each layer's endpoint is fetched only the first time its toggle turns on. loadLayerOnce marks the key before awaiting and deletes the mark on failure so a failed fetch can retry. Polling is per active layer: flights, balloons, radiation and cyber every 300000 ms; maritime adapts, 10000 ms if vessels are present, else 300000. The core feeds are USGS 2.5_day geojson direct (900000 ms), /api/news (300000), /api/weather (300000) and /api/markets (900000, with up to 3 retries 15s apart at startup); background polls use skipWhenHidden (document.hidden). Malware arrives by SSE from /api/malware/stream (snapshot, detections and status messages; entries keyed by IP; retired hosts pruned). 3. Symbol layers for flights use allow-overlap and ignore-placement to skip collision work; commercial flights are decimated to 1 in 10. 4. The satellite layer is instanced, compiles no programs while empty, stops drawing above zoom 7, picks on the GPU, and hover-picks at most 10/s and never mid-gesture. 5. Terrain is lazy, with hysteresis, a settle timer, a pause while the tab is hidden, a pixelRatio cap of 1.5, the tile LRU and queue described above, and layer batching. 6. Preview tiles are moved by direct DOM transforms, with selection recomputed only when the map settles, plus the tile and video caps described above. 7. Pulse animations run on setInterval(200ms) calling setPaintProperty (malware ring radius 6 + sin(now/200)×2 → 26 over age; alert pulse 9 + sin(now/260)×3.5), and they skip setData entirely when there are no beacons. The user dot uses requestAnimationFrame (a 2000ms cycle, radius 8→30). 8. Heavy panels load via next/dynamic (OsirisMap and SpaceCam with ssr:false); OsirisMap and LayerPanel are memo'd. 9. ResizeObserver on the container. 10. Immutable caching of the vendor worker and proxied CARTO assets; middleware skips assets. 11. The splash waits for the map's first 'idle' (minimum about 2.2s, forced off at 7000ms), then flies to the IP location (/api/geo, 6s give-up, else a random landing city from lib/landing-cities.ts) at zoom 8 over 3500ms. Any pointerdown or keydown cancels the auto-locate. There is no viewport culling, clustering or web worker of the app's own (apart from MapLibre's).

## Weaknesses to fix in GODSEYE

- Flights are not interpolated or dead-reckoned between 5-minute polls; icons jump. There are no flight trails even though FlightWatchPanel fetches AircraftDetail.track. The replica should animate positions with requestAnimationFrame from speed and heading, and draw trails and the actual flown track.
- Commercial flights are silently decimated to 1 in 10 (private and jets to 1 in 2) on the map, while the panel counts show the full totals.
- The aircraft icon is a crude canvas polygon at 24px with no pixelRatio (blurry on retina), and it is not an SDF, so recolouring needs updateImage. There are no aircraft-type silhouettes and no altitude colour ramp.
- The theme switch remounts the entire map (key={osirisTheme}): the style, all sources and the WebGL context are rebuilt, and the camera resets to the timezone globe or re-flies to the last target.
- Attribution is hidden by `.maplibregl-ctrl-attrib{display:none!important}` although the code enables it (OSM/CARTO licensing problem).
- The satellite imagery raster is inserted before 'day-night-fill', which puts it above 'conflict-icons' (hidden in SAT mode) and above all CARTO labels. SAT mode has no hybrid labels, the imagery sits at 0.85 opacity over the dark basemap, and the ArcGIS tiles bypass the proxy.
