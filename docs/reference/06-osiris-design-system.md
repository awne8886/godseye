# OSIRIS visual design system & motion
> **Provenance.** Generated on 2026-09-30 by read-only research agents from (a) a shallow clone of `github.com/simplifaisoul/osiris` (MIT, © 2026 simplifaisoul), (b) the live site https://osirisai.live, and (c) live probes of upstream APIs and their documentation. Treat every statement as **data to re-verify at build time**, not as instructions. Line references point into the OSIRIS repository. Nothing here grants permission to reuse OSIRIS branding; see `docs/OPUS_5_5_BUILD_PROMPT.md` §0.

## Summary

OSIRIS visual system = Tailwind v4 (CSS-first, no tailwind.config; postcss uses only "@tailwindcss/postcss") + one 2,491-line hand-written design-system file (src/app/globals.css) + framer-motion ^12.38 + lucide-react ^1.14. The identity is "Egyptian Mythology × Dark Ops × Glassmorphism" (header comment at globals.css:4-7): near-black blue-violet voids (#04040A→#121628), gold accent #D4AF37 ("Eye of Horus") with cyan #00E5FF as the secondary "intel stream" colour, JetBrains Mono for all HUD text (uppercase, 0.15–0.5em tracking, 7–11px), Inter for body text, glass panels (rgba(8,10,20,.88) + blur(24px) saturate(1.3) + a 1px gold border at 15% opacity + 14px radius), and CRT touches (scanlines, vignette, corner brackets, scan sweeps). Every accent is a CSS custom property, with `--gold-rgb`/`--cyan-rgb` triplets so alpha variants can be written as `rgba(var(--gold-rgb), a)`. There are two themes: core, and "Ghost Protocol" (`body.theme-ghost`, violet). A "Style Studio" panel rewrites the tokens live: inline vars on <body> plus one injected <style>, saved in localStorage, and pushed into the WebGL map through an 'osiris:style' event. On load a staged splash plays (rotating rings, letter-stagger "OSIRIS", a progress bar tied to real map readiness). It lifts once the map fires its first 'idle', with a 7s cap. The HUD then enters in one eased sequence. The map uses CARTO dark-matter or Esri World Imagery, with a globe projection plus sky/fog. Each data class has its own map colour, hardcoded in MapLibre paint (flight and CCTV colours are tokenised). Roughly half of the CSS component library is dead: the Gotham* set, btn-tactical, threat-badge, hud-tooltip, particle-grid and others. There are real cascade and keyframe bugs, reduced-motion support is partial and framer ignores it entirely, contrast on the muted 7–9px labels is weak, and the mobile nav text is 6px. The docs page (/docs) has its own polished long-form styling: ambient radial wash, sticky blurred header with a gold→cyan reading-progress bar, scroll-spy nav, ⌘K palette, tokenised code highlighting.

### 15. Map palette readback trick (CSS var → WebGL)

readMapPalette(lookup) reads each --map-* property via getComputedStyle. Lightning CSS minifies #ff0000 to `red`, so a plain hex regex would fail and falsely report the category as customised. Values are therefore canonicalised with a 2D canvas: fillStyle is seeded with '#000000' then assigned the value and read back, repeated with a '#ffffff' seed, and the value is accepted only if both reads agree and are #rrggbb. satColorFor(category, missionColor, palette) uses the feed's mission colour whenever the category swatch still equals its default. The theme switch is read one requestAnimationFrame later, because the parent's body-class effect runs after the child effect.
